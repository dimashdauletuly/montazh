## 1. Общая концепция и визуальный стиль

**Идея:** «тихая роскошь техно». Графит + жидкое серебро, всё матовое и стеклянное, один источник света сверху. Никаких ярких цветов — единственный «цвет» в кадре — бордовая футболка спикера, на её фоне серебро выглядит дороже.

### Палитра (токены)
| Роль | Цвет | Где |
|---|---|---|
| Фон глубокий | `#08090B` → `#15171C` (вертикальный градиент) | моушн-слайды |
| Свечение | `rgba(214,222,235,.16)`, радиальное пятно 900×600 вверху по центру | слайды, за PiP |
| Сетка | линии 1 px `rgba(255,255,255,.045)`, шаг 60 px, гаснет к краям (радиальная маска) | слайды |
| Серебро (chrome) | вертикальный градиент `#FFFFFF 0% → #F1F3F6 40% → #B9C0C9 54% → #E8EBEF 70% → #FFFFFF 100%` | акцентные слова, заголовки, текст за головой |
| Свечение серебра | `drop-shadow(0 0 18px rgba(220,228,240,.35))` + тень `0 4px 10px rgba(0,0,0,.85)` | все chrome-тексты |

**Цветокоррекция видео спикера — не трогаем** (цвет кожи 1:1). Только мягкий градиент-затемнение снизу (900 px, до 85 %), чтобы субтитры читались на футболке.

### Шрифт
**Montserrat** (вся кириллица + қ, ғ, ү, ұ, ө, ә, і, ң, һ).
- Субтитры: ExtraBold 62 px, акцент Black 72 px КАПСОМ.
- Заголовки слайдов / за головой: Black 140–190 px, трекинг +6.
- Подписи карточек: Bold 40 px; мелкие пояснения: Medium 28 px, 65 %.
- Надзаголовки («КЕЛЕСІ ВИДЕОДА»): Medium 26 px, КАПС, трекинг +5, `#C9CED6`.

### Сетка и безопасные зоны
- Кадр 1080×1920. Весь текст и графика: **x 78–999, y 222–1543**.
- Ниже y 1194 правый край ≤ 887 (кнопки Instagram).
- Поля слайдов: 110 px слева/справа. Вертикальный ритм — кратно 30 px.
- Голова и лицо — неприкосновенны: зазор ≥ 30 px от волос и подбородка.

### Карточки (glass)
- Скругление **36 px** (плашки-пилюли — полное), стекло: градиент `rgba(255,255,255,.14) → .04 → .07`, blur 22 px.
- Диагональный блик-«засвет» 115°, полоса 12 % ширины, `rgba(255,255,255,.10)`; при появлении карточки блик проезжает слева направо за 0,6 с (один раз).
- Тень `0 24px 60px rgba(0,0,0,.55)`.

### PiP-окно спикера
- Два вида: **квадрат-скругление** 420×400, радиус 44 px (слайд-перечисление) и **круг** 300–340 px (сравнение, финал).
- Рамка 3 px `#CDD2DA` + внешний ореол `0 0 40px rgba(210,220,235,.25)`, тень `0 30px 70px rgba(0,0,0,.7)`.
- В PiP — тот же живой видеоряд, кроп по лицу (лицо по центру, макушка с запасом 10 %). Голос не прерывается.

### Единая логика движения (главное улучшение относительно референса)
Все элементы живут по **одному правилу**, поэтому нет дёрганий:
- **Вход:** снизу +40 px → 0, прозрачность 0 → 100 %, масштаб 96 → 100 %, **0,35 с**, кривая `cubic-bezier(.2,.8,.2,1)` (ease-out).
- **Выход:** вверх −20 px, прозрачность → 0, **0,25 с**, ease-in. Выход всегда короче входа.
- **Стаггер** для групп (карточки, кнопки): **0,12 с** между элементами — или точно под слово в речи.
- **Переход спикер → слайд:** видео спикера плавно «сжимается» в PiP (scale + скругление углов растёт 0 → 44 px) за 0,45 с, фон-графит проявляется под ним. Обратно — PiP раскрывается на весь экран. То есть спикер никогда не «пропадает», он физически превращается в окно → глаз не теряется.
- Никаких вспышек, glitch, whip-pan, вращений.

## 4. Чек-лист «на уровень выше»

**Чистота**
- [ ] Одна кривая движения на весь ролик (вход 0,35 с ease-out, выход 0,25 с ease-in, стаггер 0,12 с).
- [ ] Субтитры в одной точке во всех сценах — не прыгают.
- [ ] Спикер не исчезает: переходы через превращение в PiP.
- [ ] Ничего не касается лица и волос (зазор ≥ 30 px).
- [ ] Все элементы внутри safe zone, справа снизу свободно под кнопки.
- [ ] Нет чёрных полос по краям при зуме.

**Акценты (дозировано)**
- [ ] Зумов всего 3: «Claude» (1,12), «сценарий» (1,18), медленный на хуке. Остальное — смена крупности.
- [ ] Текст за головой — только 2 раза (CLAUDE, СЦЕНАРИЙ).
- [ ] Громкий звуковой акцент — только 1 (на «сценарий маңызды»). Остальное тихо, −24…−28 дБ, под каждую анимацию.
- [ ] Голос не трогаем по громкости и тембру; при желании — лёгкая шумоочистка.

**Премиальность серебра**
- [ ] Серебро — это градиент со светлой серединой, а не серый цвет: всегда с мягким свечением и тёмной тенью.
- [ ] Блик проезжает только в момент появления (не мигает постоянно).
- [ ] Сетка на фоне почти невидима (4–5 %), гаснет к краям.
- [ ] Иконки — один набор, одна толщина линии (2,6), в металлических плитках.
- [ ] Без эмодзи в субтитрах (эмодзи → только как иконки в карточках).

**Музыка (по желанию)**
- [ ] Тихий минимал/эмбиент без слов, −30 дБ под голосом, ducking на речи; на финале чуть поднимается.

**Сдача**
- [ ] H.264, 1080×1920, длительность = исходнику, ≤ 90 МБ.
- [ ] Обложка PNG с казахским заголовком (по вашим правилам).
- [ ] Caption на казахском + 5–8 хэштегов.
